What is TimeGrid?
TimeGrid is a school scheduling and communication platform that connects teachers and students in one clean workspace. Here's what you can do:
Create Classes
Teachers set up courses, define availability, and generate a shareable code for students.
Join Classes
Students enter a 6-character code to instantly enroll in any course.
Book Office Hours
Students can view teacher availability and book sessions right from the inbox.
Message Teachers
Send messages directly to your teacher through the built-in inbox.
Step 2 of 5
Your Dashboard
The dashboard is your home base. It shows all your enrolled courses on the left, and a live weekly schedule on the right — automatically populated with your classes.
Course List
All your classes listed in the left sidebar. Click any to view full course details.
Weekly View
Mon–Fri schedule with colour-coded period slots for each class.
Create Class
Top-right navbar button opens the class creation form.
Join Class
Top-right navbar button lets you enroll with a code from your teacher.
Step 3 of 5
Classes
Teachers create a class by filling in the course name, teacher name, description, availability slots, and period. Once submitted, a unique 6-character class code is generated — share this with your students.
Example Class Code
A7KP2X
Students click Join Class in the navbar, type the 6-character code, and instantly see a preview of the course before joining.
Availability Slots
When creating a class, teachers select Pre-School or After-School slots for Mon–Fri. These appear on the course page so students know when to book.
Period Selection
Choose Periods 1–8, each mapping to a time block that shows on the weekly schedule.
Step 4 of 5
Inbox & Office Hours
Click Inbox in the navbar (or the Message Teacher button on any course page) to open direct conversations with your teachers.
Direct Messaging
Start a conversation per course. Type a message and press Enter or the send button to deliver it instantly.
Book Office Hours
Inside any chat, click Book Office Hours at the top right. Pick an available time slot set by your teacher, describe what you need help with, and confirm — a booking card appears in the chat.
New Message
Use the + New Message button in the left panel to start a conversation for any enrolled course.
